# Reference gallery sources

This note records sources for the initial five *Harry Potter and the Philosopher's Stone*
promotional photos or film stills, plus one same-period actor reference per character.
The current gallery has 17 supported `.jpg`/`.png` photos; this source note does not yet
list a source for every later owner-curated addition. The `.avif` and `.webp` files in the
gallery are versioned but are not read by the pipeline. The age in each descriptive filename
is the actor's age at the London world premiere (4 November 2001), which is also unchanged
at the UK theatrical release on 16 November.

| Prof. Severus Snape | Alan Rickman, 55 | https://www.pinterest.com/pin/snape-harry-potter-and-the-philosophers-stone-2001--910923462124741169/ |

Each character folder also contains one non-costumed actor reference from the same period:

- Daniel Radcliffe and Rupert Grint: New York *Sorcerer's Stone* premiere, 11 November 2001.
- Emma Watson: UK *Philosopher's Stone* premiere, 4 November 2001.
- Maggie Smith: *Gosford Park* New York premiere, 3 December 2001 (Getty Images editorial preview, photo by Gabe Palacio/ImageDirect).
- Alan Rickman: 2001 portrait published by BBC News.
