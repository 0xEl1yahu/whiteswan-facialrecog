# Documentation Archive

These files preserve approved designs, implementation plans, and engineering investigations
from completed milestones. They are historical evidence, not live instructions or current
status. Unqualified words such as “current,” “accepted,” and “next” refer to the dated
snapshot in that document.

Use these current authorities instead:

1. [`docs/STATUS.md`](../STATUS.md) for the active branch state, decisions, artifacts, and
   next work.
2. [`docs/design/design-plan.md`](../design/design-plan.md) for normative requirements and
   data contracts.
3. [`docs/implementation/implementation-plan.md`](../implementation/implementation-plan.md)
   for the single live checklist.
4. [`README.md`](../../README.md) for setup and operator instructions.

Archived checkboxes record the execution history of their original plans. They must not be
used to infer current milestone status.
